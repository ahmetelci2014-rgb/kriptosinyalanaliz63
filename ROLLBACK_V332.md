# Panel V3.32 rollback note

2026-08-16 tarihinde mobil dokunma ve FREE/PREMIUM sunum regresyonları nedeniyle aktif dashboard runtime V3.32 Market/Coin UX katmanına geri alınmıştır.

Bu geri dönüş yalnız panel sunum/runtime seçimidir. Canlı sinyal motoru, Telegram, TP/SL/BE, state/ledger, radarlar ve üyelik/ödeme backend'i değiştirilmez.

V3.33+ panel dosyaları inceleme amacıyla repoda tutulur ancak aktif runtime değildir.
