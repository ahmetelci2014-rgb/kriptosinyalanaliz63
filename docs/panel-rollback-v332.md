# Panel rollback: V3.32

Active dashboard runtime was rolled back to V3.32 on 2026-08-16 after mobile interaction and FREE/PREMIUM presentation regressions were observed in later UI-only layers.

Scope: dashboard runtime selection and its regression contract only.

Not changed: live signal engine, Telegram delivery, TP/SL/BE logic, radar logic, state/ledger writes, membership/payment backend.

V3.33+ dashboard modules remain in the repository for later diagnosis but are inactive.
